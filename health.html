How it works

Review every parsed field before saving. Parsing is a basic text helper, not medical-grade OCR.

1

Paste labelled text

Use headings such as “Medication Name:” to identify each entry.

2

Review each draft

Correct names and fields. Missing details remain unspecified.

3

Confirm and save

Only checked entries are added to your local medication list.

Example format

Medication Name: Example Medicine A
Strength: 10 mg
Dosage Instructions: As written on the prescription
Frequency: Not specified
Route: Not specified

Medication Name: Example Medicine B
Strength: Not specified
Dosage Instructions: Not specified
Frequency: Not specified

Example placeholders only. They are not medical recommendations.
